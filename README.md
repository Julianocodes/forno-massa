# Forno & Massa — cardápio demonstrativo

Projeto de estudo de uma pizzaria fictícia. A interface permite explorar sabores, escolher tamanho e quantidade e acompanhar um carrinho com subtotal, desconto demonstrativo e total.

> Este é um exercício de front-end baseado nos estudos de JavaScript com a B7Web. Os textos, imagens e preços são ilustrativos. O projeto não envia pedidos, não processa pagamentos e não representa uma pizzaria real.

## Funcionalidades

- Catálogo de sabores renderizado a partir de dados JavaScript.
- Janela de detalhes com escolha de tamanho e quantidade.
- Carrinho com inclusão, remoção e ajuste de quantidades.
- Cálculo de valores e desconto de demonstração.
- Carrinho preservado no navegador com `localStorage`.
- Aviso transparente ao tentar revisar o pedido: nenhum pedido é enviado.
- Layout adaptado para telas menores e controles utilizáveis por teclado.

Os preços usam valores de exemplo e multiplicadores simples por tamanho apenas para demonstrar os cálculos do carrinho.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Web Storage (`localStorage`)

## Como executar

Não é necessário instalar dependências. Clone ou baixe o repositório e abra `index.html` no navegador. Também é possível usar a extensão Live Server do VS Code.

## Aprendizados praticados

- Renderização de componentes a partir de dados.
- Eventos de interface e manipulação do DOM.
- Estado do carrinho, cálculos e persistência local.
- Layout responsivo e elementos HTML semânticos.
